# 🌸 My Personal Learning Tracker

A simple, aesthetic, and responsive web application designed to help me build consistent study habits, manage daily tasks, and track my learning progress throughout the month.

🔗 **Live Demo:** [My Personal Learning Tracker](https://joairya-afnin.github.io/Personal-Learning-Tracker/)

## ✨ Features

- **Overview Dashboard** — Get a quick summary of monthly task completion, average progress, and your target benchmark.
- **Habit Calendar** — Navigate between months and select a specific date to track daily habits.
- **Daily Habit Tracker** — Check off completed habits and monitor daily completion progress.
- **Monthly Task Tracker** — View daily records and monthly completion percentages for each habit.
- **Progress Visualization** — Compare habit completion rates and review overall monthly performance.
- **Responsive Design** — A clean interface designed to work across different screen sizes.
- **Local Data Storage** — Keep track of your progress on your device.

## 📚 Habits I Track

The application focuses on three daily habits:

1. **Study One University Topic** — Complete one focused study session.
2. **Reduce Digital Distractions** — Minimize phone usage and turn off unnecessary notifications.
3. **Read for 20 Minutes** — Spend time reading without interruptions.

The monthly progress dashboard uses a **90% completion benchmark** to encourage consistency.

## 🛠️ Technologies Used

- **HTML5** — Structures the application and its content.
- **CSS3** — Styles the interface and provides custom visual elements.
- **Tailwind CSS** — Supports utility-based styling.
- **JavaScript** — Handles habit tracking, calendar interactions, progress calculations, and CSV export.
- **Google Fonts** — Uses DM Sans and Plus Jakarta Sans for typography.
- **Git and GitHub** — Version control and project hosting.
- **GitHub Pages** — Publishes the application online.

## 🚀 Getting Started

You can run the project locally by following these steps.

### Prerequisites

A modern web browser and a code editor, such as Visual Studio Code.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/joairya-afnin/Personal-Learning-Tracker.git
   ```

2. Open the project folder:

   ```bash
   cd Personal-Learning-Tracker
   ```

3. Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.

No build process is required for the current version.

## 💡 How to Use

1. Open the [live website](https://joairya-afnin.github.io/Personal-Learning-Tracker/).
2. Navigate to the Habit Calendar and select a date.
3. Complete your daily habits by checking the corresponding boxes.
4. Review your records in the Monthly Task Tracker.
5. Visit the Progress section to evaluate your monthly performance.
6. Use **Export CSV** to download your tracking data.
